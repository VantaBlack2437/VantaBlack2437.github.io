# Vishesh Kandadai Portfolio

A React portfolio built with Vite and deployed to GitHub Pages.

## Local development

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, or preview it locally with `npm run preview`.

## GitHub Pages

Vite is configured with the root base path for `https://VantaBlack2437.github.io/`. The GitHub Actions workflow in `.github/workflows/deploy.yml` builds and deploys the site when changes are pushed to `main`.
